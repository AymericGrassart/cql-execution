## 2025-05-18 - Fast-pathing Cartesian products for single-source queries
**Learning:** In `cql-execution`, CQL queries iterate over sources via `cartesianProductOf(sources)`. In clinical CQL workloads, the vast majority of queries have only a single source alias (e.g. `[Encounter]`). Running general Cartesian product functions on single-source inputs using `sources.reduce(...)` with `a.forEach(...)` and `a.concat([b])` incurs heavy array allocation overhead ($2N$ arrays created per query) and closure invocations.
**Action:** When evaluating queries or combinatorial functions, always check for single-source fast paths: preallocate `new Array(len)` and wrap each item directly as `[s0[i]]`. For multi-source queries, use indexed for-loops and spread expressions rather than `forEach` and `concat([b])` to eliminate temporary single-element wrapper allocations.
